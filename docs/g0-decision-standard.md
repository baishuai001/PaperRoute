# G0 科研方向决策标准

本文件规定 PaperRoute 如何从锚点论文产生、比较和批准候选方向。它落实
`PROJECT_DISCIPLINE.md`，优先级高于任何单篇论文的 G0 报告。

## 1. G0 的任务

G0 不是寻找“与锚点最像”或“风险最低”的题目，也不是发现锚点问题后自动把
问题本身变成新论文。G0 的任务是：

1. 明确本项目希望从锚点复用什么；
2. 区分锚点的硬伤、普通限制和可利用机会；
3. 生成包含不同复用方式和改编幅度的候选组合；
4. 分别审计科学有效性、可行性、新颖性、科学价值、负担、学习价值和锚点复用；
5. 把互有取舍的候选交给项目负责人选择，不用一个不透明总分替代判断。

## 2. 核心定义

### 2.1 科学有效性（scientific validity）

一个候选方向的中心问题、构念、分析单位、比较关系、数据、统计设计和结论层级
能够形成有效推断。每项核心主张必须说明：

- 研究对象和目标人群；
- 生物学单位或患者单位；
- 比较、暴露、干预或目标效应；
- 主要结局；
- 关键偏倚、混杂和对照；
- 能支持该主张的证据层级；
- 什么结果会否定或实质削弱它。

显著性、复杂模型、漂亮图件和代码可运行都不能替代科学有效性。

### 2.2 可行性（feasibility）

在确认的数据、metadata、代码或方法 donor、计算、时间、技能、访问权限和实验资源
下，能够完成支撑中心主张的最低证据链。可行性审计面向最低充分稿件，而不是愿望清单。

- `pass`：关键依赖已确认；
- `conditional`：存在可在下一 gate 用小规模检查解决的关键未知；
- `fail`：不可替代的核心依赖缺失；
- `unknown`：证据不足，不能推荐。

“存在公共数据集”不等于可行；必须确认样本单位、所需字段、队列独立性、数据规模和
适用方法。作者代码缺失通常是实现风险；只有在关键方法无法独立重建、验证或替代时，
才成为路线级不可行。

### 2.3 新颖性与科学价值

二者必须分开。

- **新颖性（novelty）**：最近邻文献尚未回答什么；
- **科学价值（scientific value）**：这个答案会改变什么认识、解释、决策或方法实践。

创新审计必须同时给出：最近邻证据、新增内容、重要性和决定性结果。替换癌种、基因集、
细胞、结局或方法都可以构成创新，也可能只是机械重命名。改变数量不是创新指标。

修复锚点硬伤默认只恢复可信度，不自动计为新颖性。只有当修复产生可推广的新方法、
系统性新证据或改变领域认识时，才可另行主张创新，并接受最近邻审计。

### 2.4 硬伤、限制和机会

- **硬伤**：不处理就会使某项主张无效、不可解释、不可复现或无法实施；
- **限制**：降低精度、适用范围或结论层级，但不必然否决主张；
- **机会**：可用于形成新增问题或证据，但不是必须修复的错误。

硬伤必须标明影响范围：`claim`、`module`、`resource` 或 `route`。只有不可替代、无法
降低主张且直接破坏中心问题的硬伤，才能否决整条路线。其余应修复、换资源、删除局部
组件、降低主张或如实披露。

### 2.5 方向、改编和重定向

方向是一个稿件内核：中心问题、分析单位、关键关系、主要结局、决定性证据和主张层级。

在 G0 批准前，换癌种、对象、关系、结局或证据结构都是候选改编，不叫重定向。批准后，
若中心问题、目标效应、主要结局、决定性证据或稿件贡献类型发生变化，使原证据链不再
回答新问题，才是 `reroute`，必须新建版本并重新评审。

换数据集、修代码、纠正统计单位或增加回答同一问题的验证通常属于 `refine`，不自动
构成重定向。

## 3. 多轴变换模型

每个非 umbrella 候选必须对五个核心轴各记录一次操作：

1. `disease_context`：疾病、组织、患者或临床情境；
2. `biological_object`：基因集、细胞、通路、分数或其他核心对象；
3. `central_relation`：候选要检验的中心关系或假设；
4. `primary_outcome`：主要生物学或临床结局；
5. `evidence_architecture`：决定性证据及其组织方式。

还可记录数据、方法、代码和主张层级。每个轴的操作是：

- `retain`：保留；
- `repair`：为恢复科学或计算正确性而修复；
- `replace`：替换为新的科学要素；
- `extend`：增加新要素或证据；
- `drop`：删除无法支持或无必要的部分。

允许同时改变任意多个轴。约束不在数量，而在于每个变化都必须有科学理由、贡献角色、
所需证据、donor 计划和风险说明。多项变化之间还必须具有一致的科学问题，不能通过堆叠
数据和分析制造表面创新。

## 4. “最小充分”的正确含义

“最小”约束无必要的研究负担，不约束与锚点的表面距离：

> 在足以形成明确、可信、新颖贡献的前提下，不加入对中心结论无必要的问题、数据、方法、
> 图件或主张。

多轴替换可以是最小充分方案；单轴改变也可能是实质换题。若删除某项改变后贡献仍完整，
该改变可能是不必要复杂度。若多个改变共同构成不可分割的新问题，应作为一个组合接受
科学性和可行性审计。

## 5. 候选方向必须独立评估

每个稿件候选必须分别记录：

- 科学有效性及其依据；
- 可行性及关键依赖；
- 新颖性及最近邻文献；
- 科学价值；
- 实施负担；
- 学习价值；
- 锚点复用程度；
- 关键取舍和致命阻断条件。

这些维度不能合并成“雄心层级”，也不能用一个总分掩盖取舍。科学有效性和不可替代的
可行性依赖是硬门槛；其余合格候选形成组合，由项目负责人根据稿件目标和资源选择。

## 6. G0 必须提供的候选组合

候选不按改动多少机械排序。原则上应覆盖：

- 高复用或修复型方案；
- 有生物学理由的单轴或多轴改编；
- 锚点 A 提供问题或设计、文献 B 提供方法或代码的组合；
- 证据或机制扩展方案；
- 必要时的训练复现、停止或更换锚点方案。

不存在某类方案时，应说明原因。AI 可以提出推荐，但不得把 `proposed` 写成已批准判断，
也不得让“最安全的审计问题”自动胜出。

## 7. 人工批准条件

项目负责人批准前，应能用普通语言回答：

1. 新稿究竟研究什么？
2. 从锚点保留、修复、替换、扩展和删除了什么？
3. 每项变化为什么必要，它贡献新颖性、科学价值还是仅修复正确性？
4. 决定性结果是什么，什么结果会否定方向？
5. 最低数据和可靠代码从哪里来？
6. 与其他合格候选相比，选择它牺牲了什么、换来了什么？

任何一个问题无法回答，G0 保持开放，不进入全量下载和实现。
