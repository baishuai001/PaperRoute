# SPP1+TAM JITC pilot

This is a lightweight PaperRoute instance for:

> Targeting SPP1+TAMs associated with liver metastasis reverses
> immunosuppression and synergizes with immunotherapy in colorectal cancer.

The pilot is intentionally at `G0_DIRECTION`. It does not claim that the
illustrative direction has been approved, and it does not contain the source
PDF, raw sequencing data, controlled data, or paper-specific unpublished
inputs.

Its purpose is to demonstrate:

- an anchor paper;
- a proposed direction;
- a proposed claim;
- candidate data, method, and code resources;
- a high-risk direction decision;
- a pending human review;
- dependencies used for impact analysis.

Run:

```bash
paperroute validate examples/spp1-tam-jitc
paperroute status examples/spp1-tam-jitc
paperroute impact examples/spp1-tam-jitc DIR-001
```

The scientific content remains illustrative until the direction audit and
review are completed.
